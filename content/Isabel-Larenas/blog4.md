# What I Worked On

For Phase 4 of the project, we worked on finalizing our website. My biggest contribution was creating and deploying our second machine-learning model, a linear regression built for the government agency user persona. This model predicts housing deprivation across Europe based on a range of socioeconomic indicators, including immigration, housing-cost overburden, GDP per capita, population density, and unemployment. To get there, I first cleaned and merged the EU datasets for each of those indicators into a single training set, and built out a Jupyter Notebook to explore the data and understand how the different factors related to one another before settling on the model. On the backend, I added the routes to our Flask API for training, testing, prediction, parameters, and the deprivation-map endpoint that powers the Europe heatmap.

On the frontend, I built the Streamlit page for the model, which features an interactive heatmap of Europe alongside a table that ranks countries by how much funding they need most, so the agency persona can quickly see where deprivation is highest. In addition to my main model, I also contributed to the student life satisfaction prediction model and wrote the project README to document our work and make it easy for others to set up and navigate the repository. Overall, getting to take a model from raw datasets all the way through to a deployed, interactive page was something that I have never done before and am very proud of myself for doing.
